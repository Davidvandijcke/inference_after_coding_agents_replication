# Uniform coding clarifications

These clarify the frozen descriptive schema and apply to every partition. They do not change the accepted independent match labels or the numerical correction.

1. Explicit permanent-closure zero recoding plus explicitly unrestricted/no-extra-filter follow-up status eligibility qualifies as `closure_recoding`. The stated eligibility set may be all statuses, rather than only response/closure statuses. Preserve baseline and required-variable details.
2. Merely including a closed store only when its recorded follow-up counts are already zero is not a recoding operation. If that declaration imposes a broader explicit status filter outside the respondent-only rule, use the residual sample category.
3. Descriptive coding prioritizes the three display dimensions and their material evidence/coherence. The complete frozen declarations retain all other restrictions. Missing detail fields must not be presented as newly inferred probability assumptions.
4. Explicit full-time-count controls may use aliases such as Ypre, Y_i,pre, FTE0/1, or B. Use the declared meaning and conditioning expression, not an alias in isolation or a baseline mention in outcome construction. Chain-specific intercepts with a common NJ slope remain additive chain effects; actual NJ-by-covariate or chain-specific NJ slopes are residual.
5. A part-time-only measure described generically as a headcount is residual, not total employee headcount. Full-time count plus managers, without part-time weighting, belongs to full_time_employees with manager inclusion recorded; it is not manager-inclusive FTE. Manager-only measures are residual.
6. An actual rule retaining only chain categories represented in both states is a sample filter and is residual. A global rule that stops an otherwise unchanged fit if the full sample lacks required support is an estimability condition, not a row filter.
