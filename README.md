# Replication package for "Inference After Coding Agents"

Florian Gunsilius, David Van Dijcke and Kaspar Wüthrich

## Overview

`run_all.sh` rebuilds every table and figure of the paper from the data in this package and compiles the paper.
It runs twelve modules in `code/`, which write to `paper/tabs/`, `paper/figs/` and `results/numbers/` (the
numbers the text states). A full run takes about 8 minutes on a laptop and calls no language model.

The paper's evidence comes from coding agents that analyzed data and were then replayed on subsamples of it. The
recorded outputs of those sessions are data generated by the authors and are included (`data/agent_runs/`).
Agent sessions cannot be reproduced exactly, since the models sample their outputs, so `run_all.sh` starts from
the records. The code needed to run the agents and build the records again is in each module's
`data_generation/` folder, and each module's `README.md` lists it as steps.

The records hold what the analysis uses: each original's declared model and null, report, p-value and program,
and each replay's subsample, stratum, declaration and match verdict, with the verdicts of reviewing agents where

transcripts, which print rows of the ISSP microdata.

## Computational requirements

### Software

- [x] The replication package contains one or more programs to install all dependencies and set up the necessary
  directory structure (`environment/setup.sh`).

- macOS or Linux with bash. Tested in full on macOS 26.3 (Apple silicon). On Linux (Red Hat Enterprise Linux
  8.10), modules 00 to 10 wrote every table and figure byte for byte as on macOS in a test of 15 November 2026.
- Python 3.12 or later (tested with 3.14.2); `environment/requirements.txt` pins the packages. Module 00 runs in a
  second environment with matplotlib 3.11.2 (`environment/requirements-lens.txt`).
- R 4.5.1 with data.table, haven, jsonlite and sandwich (`environment/install_r_packages.R`).
- TeX Live 2025 (pdfTeX, latexmk, BibTeX), Ghostscript 10 and Poppler (`pdftotext`), for the paper and the prompt
  displays.

`environment/setup.sh` needs internet access (PyPI and CRAN); `run_all.sh` needs none.

### Controlled randomness

Every random draw uses a fixed seed, set in the script that makes it. Language-model sessions are not seeded;
their recorded outputs are data.

### Memory, runtime and storage

About 8 minutes on an Apple M1 Pro laptop (16 GB), with at most two cores and 1.5 GB of memory. The package
occupies about 370 MB, and a run writes about 50 MB to `data/derived/`.

## Description of programs

- `run_all.sh` runs the modules and compiles the paper; logs go to `logs/`.
- `code/NN_<module>/` holds `run.sh`, the numbered analysis scripts it runs, a `README.md`, and `data_generation/`:
  the code that produced the module's agent records and intermediate results (data builders, the prompts and other
  inputs the agents received, the session runner, the builders of subsamples, and the reviewers behind labels), as
  it ran, with paths, accounts and hosts replaced by placeholders. `run_all.sh` does not run it. Earlier versions,
  job files and helper scripts of the runs are available from the authors.
- `code/lib/replay.R` is the estimator: the corrected p-value and multiplier, the confidence interval and the
  allocation of replays. `code/lib/paper_numbers.py` writes `results/numbers/<module>.json`, which lists each
  number the text states with the sentence that states it and the value computed here.
- `paper/` holds the paper's LaTeX source and the `figs/` and `tabs/` folders the modules fill.

The code is licensed under the MIT License (`LICENSE.txt`).

## Instructions to replicators

1. Install Python, R, TeX Live, Ghostscript and Poppler, with `python3`, `Rscript`, `latexmk`, `gs` and
   `pdftotext` on the `PATH`.
2. Run `bash environment/setup.sh` from the package root (set `PYTHON_BIN` to choose the interpreter).
3. Run `bash run_all.sh`. It prints each module's runtime and ends with `paper/main.pdf`.
4. `shasum -a 256 -c expected_outputs.sha256` confirms that the 22 tables and figures match the authors' run byte
   for byte. With other versions of matplotlib or TeX Live a figure can differ in its bytes and show the same
   values.

A module can be run alone, for example `PYTHON="$PWD/.venv/bin/python" bash code/01_fixed_design/run.sh` (use
`.venv-lens/bin/python` for module 00). Module 02 reads the results of modules 01 and 03.

### Known discrepancies

Every table and figure is reproduced as printed. In the following statements of the text the records give
another value, which is the one in `results/numbers/`.

| Module | Statement in the text | Records |
|---|---|---|
| 02 | 40 + 200 and 240 + 400 replays per analysis | one analysis has 9 and 43 tail replays, because its bank held too few tail subsamples |
| 03 | 40 tail replays per analysis | one analysis has none |
| 04 | 40 tail replays per analysis | 31 of 99 analyses at the larger effect have fewer, 3 of them none |
| 05 | the repair agent is the "same model as the original" | the repair ran Claude Sonnet 4.6 for every cohort |
| 06 | the outcome is coded 1 = "definitely should not be"; the original tried six specifications; 13 of 20 and 11 of 20 reruns lead with the original's analysis | the archive codes 1 = "definitely should be" (the 0-100 outcome has the right direction); the log holds 14 estimated analyses; 14 of 20 and 12 of 20 |
| 08 | 99.5% of replays pass "after a second model audits" | 99.5% is the share after the authors' audit of the reviewer's verdicts |
| 10 | Figure 10's caption counts 40 runs with a Holm or Bonferroni correction | 38, and 2 with another adjustment |
